Lookstow

Back up Microsoft 365 mailboxes to a folder on your own disk, and keep the copy up to date, on Windows and Linux.


        
      

      

      


      

        
          
          Manual Download
        
      

    


    

      
What it does

      
Lookstow is a service for Windows and Linux that keeps a copy of your Microsoft 365 mail on a disk you control. It finds the mailboxes in your tenant, copies every message, and keeps the copy up to date. You run it from a console in your browser at http://127.0.0.1:8030, on the computer it is installed on.

      
    
        
  • Backs up user mailboxes, shared mailboxes and online archives
    • 
        
  • Finds new mailboxes in your tenant by itself, and keeps up with new mail
    • 
        
  • Stores everything in a folder on this computer, so the copy is yours
    • 
        
  • Runs as a service (Windows service or systemd): starts at boot with no login
    • 
        
  • The console answers on this computer only (127.0.0.1)
    • 
        
  • Updates itself from GitHub with signed releases, and keeps your data and settings
    •
